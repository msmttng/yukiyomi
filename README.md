# ユキヨミ（国内スキー場の降雪予報）

個人・仲間内で使うための、静的な1ページのサイトです（GitHub Pages で公開）。

- サーバー側の処理や GitHub Actions は使っていません。予報・実測データは、閲覧したブラウザが各提供元から直接読み込みます。
- 他サイトのカメラ画像を保存・再公開していません。YouTube のライブはサムネイル、skiday の積雪カメラは提供元の埋め込み機能で表示し、それ以外は公式ページへのリンクです。

## データの出典
- 気象予報：Open-Meteo.com（CC BY 4.0）。モデル：JMA・ECMWF IFS・NOAA GFS・DWD ICON
- 予備の予報：MET Norway（CC BY 4.0）
- 実測：気象庁ホームページ（アメダス）を加工して作成
- 地形：国土地理院（地理院タイル）
